# Structured PCV programme analysis

Reproducible research assets for an age–calendar vaccination modelling study.
The manuscript links continuous-time probability dynamics, cohort ODEs and
age–calendar transport under matched conditions, then illustrates the structure
with three separately evaluated PCV product scenarios.

The manuscript-linked version is **v1.0.1 (2026-11-03)**:
[fixed release and download assets](https://github.com/Raymond-Zhou-2005/pcv-structured-model/releases/tag/v1.0.1).
It incorporates the 2026-11-03-r1 manuscript, mathematical arguments,
publication-sized figures and saved-trajectory CFR audit. The 144 simulation
inputs and numerical outcomes are retained from v1.0.0.

`manuscript.pdf` is the publication-aligned PDF; only its availability paragraph
has changed since the reviewed manuscript. `manuscript_overleaf.pdf` preserves
the exact author-provided Overleaf export, including its original availability
wording. Research prose, main tables and figure contents are retained.
`paper/main.tex`, the Overleaf download and `manuscript.pdf` use the same release
identifiers. Original v1.0.0 assets remain available under their unchanged tag.

## Quick start

The fully validated reference platform is **Windows x86-64, CPython 3.12.14**
with the locked dependencies: the complete rerun passed 811/811 checks.
One Ubuntu/Python 3.12.15 run passed the same 811 checks; an earlier Linux
runner completed the analyses and figures but failed 27 very strict
output-column comparisons. General Linux portability is therefore not
established by these two runs. The original acceptance
tolerances and scientific solver are unchanged; see
[`checks/portability/README.md`](checks/portability/README.md) and the release's
`validation.zip` for the retained diagnostics. Use tag `v1.0.0` for the exact
base numerical source; the default branch also contains subsequent audits.
The present revision rechecks the retained outputs; it does not claim a new
full 144-configuration simulation run.

Python 3.12 was used for the recorded run. From a clean environment:

```sh
python verify_release.py
python -m pip install -r requirements-lock.txt
python reproduce.py
```

Run the SHA-256 check before reproduction, which regenerates output files.
`requirements-lock.txt` records all packages in the publication validation
environment; `requirements.txt` records the direct dependencies.
The manually dispatched GitHub Actions workflow runs the complete default
pipeline on Linux as an experimental portability diagnostic. Its status records
computational checks, not empirical calibration or journal acceptance. To compile the manuscript, run
`tectonic main.tex` from `paper/` with an output directory of your choice, or
import the release's `overleaf.zip` into Overleaf and select `main.tex`.
After numerical validation and compilation to `manuscript.pdf`,
`python write_manifest.py` refreshes the current file hashes, and
`python package_release.py --output-dir ../downloads` rebuilds the independent
Overleaf, repository and combined download archives. Use an empty output
directory; the packaging script does not overwrite existing archives.

The default command reruns the 144 application configurations, independent
accounting checks, mathematical/refinement experiments, historical controlled
reconstructions, numerical source-ledger checks, the constructed CTMC
distribution experiment, all six main figures and nine extended trajectory
figures. It then checks the outputs against retained reference tables.
It does not download clinical data or contact external services.

Useful subsets:

```sh
python reproduce.py --stage check
python reproduce.py --stage plots
python reproduce.py --stage analysis
python reproduce.py --with-cohort
```

The saved-trajectory diagnostic can also be run on its own:

```sh
python checks/revision_20261103/cfr_translation_audit.py
```

It reconstructs monthly exposure and the case/fatal-event reward mapping from
all 144 saved trajectories. It quantifies the inherited probability-to-hazard
convention while keeping the simulated population and economic outputs fixed.
It is included in the default and `--stage check` pipelines.

The optional `--with-cohort` regenerates the retained 4,000-replicate discrete
closed-cohort audit using seed 20261004. The default validates its stored
replicate-level records instead. The constructed CTMC's 4,000 terminal samples
are regenerated by the default pipeline; observations at its four times are
independent terminal draws, not linked trajectories.

All paths are relative to this repository. The scientific pipeline runs from
any working directory and does not require the authors' Windows drive layout.
The output logs are in `checks/logs/`; the final check summary is
`checks/verification.json`. Runtime varies by machine and is not a performance
claim. On the reference environment the core calculations take several minutes;
high-resolution figure export adds time.

`checks/publication_validation.json` records the fresh publication-environment
rerun and its comparison with the preceding frozen release. All 144 state
arrays meet the declared tolerances; differences need not be bitwise zero
between Python distributions. Earlier imported audit records describe their
own recorded environments and are retained as provenance.

## Data and interpretation

This repository contains **aggregate model inputs and simulated outputs**, not
patient-level clinical records. An exact citation identity, a recovered
arithmetic operation, and an independently validated epidemiological parameter
are different evidence levels. `research/sources/parameter_sources.csv` records
the distinctions for every flattened input.

The PCV application is a deterministic scenario demonstration. Birth seasonality,
dose opportunities, attained-age waning, indirect-protection mapping and product
bridging include declared structural or transferred assumptions. Several local
costs, utility observation windows, national age weights and a common monetary
base year remain unverified. Currency is scenario USD. The SII summary multiplier
can be multiplied reproducibly, but its original serotype-level derivation is
not recovered. The AOM endpoint is pneumococcal-attributable with a frozen
0.303 proxy. There is no reproducible joint calendar-model parameter PSA.

The constructed CTMC distribution check describes conditional count variation
and absorption probability under fixed rates. It is not a PCV clinical risk
prediction. Its count prediction interval is different from a confidence
interval for a simulated mean and from parameter uncertainty. In the retained
discrete cohort summaries, the saved death reward is a conditional expectation
from sampled disease episodes; it must not be treated as an integer death-count
distribution for tail-risk estimation.

## Provenance, permissions and versioning

`checks/import_manifest.json` identifies the frozen source bundle and imported
scientific file hashes. New release manifests identify current repository files
and the manuscript version. Runtime timing fields and sub-tolerance floating
point roundtrips are not expected to be bitwise portable; comparison tolerances
and actual differences are reported in the checks.

they are not used as runtime locations. Earlier manuscript packages, duplicate
publication builders, Python caches, compiled documents and nested release ZIPs
are deliberately excluded from this research tree.
